id: DEC-006
title: Keep review interfaces disposable and canonical records authoritative
status: accepted
context: >-
  VEF audits, migrations, and reconciliations can produce dense but valid Markdown changes that still require human
  judgment. Git diffs and linear ledgers are durable but not always an effective review experience. Earlier roadmap
  items proposed a rendered website and an Obsidian plugin, but they did not define a shared acceptance and comment
  boundary.
decision: >-
  Add a tool-neutral human review layer as a disposable projection of canonical VEF state. A review bundle may contain
  rendered documents, normalized records, typed graph context, validation results, provenance, candidate diffs, review
  queues, and comments anchored to stable targets. Comments are stored in an exportable review packet and remain
  untrusted review evidence until explicitly reconciled into canonical Markdown and accepted by strict validation. The
  initial review UI must not own a project database or silently mutate canonical records. Obsidian, wiki, static-site,
  and future hosted adapters consume this shared contract rather than defining competing formats.
rationale: >-
  Humans need a lower-friction way to understand and annotate agent-produced project state, while VEF's portability
  depends on Markdown and Git remaining authoritative. A neutral ephemeral bundle provides useful interaction
  immediately, avoids requiring a hosted product, and prevents each UI adapter from inventing its own parsing, comments,
  and write-back semantics.
consequences: >-
  Positive — faster human acceptance, visible provenance and uncertainty, portable review handoffs, reusable UI
  adapters, and no new canonical store. Negative — VEF must version stable review targets and comment packets, secure
  rendering of untrusted content, distinguish review from acceptance clearly, and eventually connect approved feedback
  to the validated mutation layer. Exported review packets may contain sensitive project context and require explicit
  handling guidance.
